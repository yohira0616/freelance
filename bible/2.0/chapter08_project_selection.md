# 第８章: 稼げる案件を見極める3つのポイント

> 出典: [Notion - フリーランスエンジニア完全攻略バイブル(Version2)](https://app.notion.com/p/55a3be6b8b3e440f9b31065671c7f778)

「フリーランスの案件獲得から入金までの具体的なフロー」について理解できたところで、この段落ではみんな知りたい「**稼げる案件を見極めるポイント**」について解説していきます。

まず大前提として理解しておいてもらいたいのが、「**フリーランスとして生き残りたいのなら、「稼げる案件を選択し、稼げない案件は捨てる」必要がある**」ということです。

**「舞い込んでくる案件を全部闇雲に受けていたら成功できる」なんてことはありえません。「神の見えざる手」は存在しません。**

「技術力があればそれ相応の稼げる仕事をエージェントが勝手に持ってくるだろう」そんなことはないです。営業は自分のノルマを達成したいからダメ元で提案している、みたいなケースは枚挙に暇がありません。

**あなたが手を動かす工数は「限定品」です。稼げない仕事で工数を埋めるということは、他の稼げる仕事を蹴ることだ、ということを理解してください。**

ちょっとSNSなどでは炎上しそうなので言いづらいのですが、せっかく記事を購入していただいたあなただけにお伝えすると、

**IT業界は広く、そしてこの事実に気づいていない人が多数存在する「情報の非対称性が大きい」マーケットです。**

稼げない仕事は（感謝と祈りを込めて）他の人にやってもらうことにしましょう。

さて本題に入ります。

私が考える稼げる案件の3つのポイントとは

- 商流が浅い案件
- 自社サービス開発など継続性の高い案件
- 儲かっている会社の案件

です。

順番に見ていきましょう。

## 商流が浅い案件

**商流が浅い案件は稼ぎやすい、というよりは、商流が深い案件は極端に稼ぎにくくなります。**

例えば、エンド→SIer→エージェント1→エージェント2→自分という商流があったとして、間に挟まっている会社が20%ずつマージンを抜いたというケースを考えます。

マージン率20%というのは各社ぼったくっているわけでもなく良心的な割合ですが、自分の取り分はどうなるでしょうか。

この時、自分の取り分の割合は **100 * 0.8 * 0.8 * 0.8 = 51.2%。**

エンドが100万払っているのにあなたの単価は51万です。

**悪徳業者は存在しないのに、構造上半分持っていかれてしまいました。**

これなら還元率60%~ の高還元SESで正社員をやった方がマシです。

また、商流が深いと値上げしづらいです。例えばあなたが単価交渉をして60万欲しいと言ったとしましょう。

この時エンドはいくら支払うことになるでしょうか。

**60 / (0.8)^3 = 117 万**

**9万値上げするのに二倍近く、17万のエンドの値上げが必要になってしまいました。**

こういう感じなので、たとえ**あなたがきちんとした付加価値を提供しても商流が深い案件で単価をアップさせていくのは至難の業**です。

ここで注意しなければならないのは、**「大規模案件」と銘打っている案件は商流が深いことが多い**ということです。（いわゆる多重下請け構造）

**プロジェクト全体で動いている金額で入る案件を評価するのではなく、規模は小さくても商流が浅い案件を選んだ方が絶対に良い**です。特に、小さい案件は目の前のPMの信頼さえ勝ち取れば値上げできるケースも少なくないです。

## 自社サービス開発など、継続性の高い案件

**「6ヶ月でシステムを構築して納品して終了」のような期限があるプロジェクトより、「プロダクトを継続運用・改善していく」継続開発案件の方が儲かります。**

前者の売り切り案件の問題点は大きく分けて二つ。

一つ目は、**プロジェクト終了から次の案件探しまでの間にブランクが発生する**こと。

エージェントが一定の案件をプールしているので2~3ヶ月空く、ということは少なくなってきましたが、それでも「新規案件探し→実際に現場にジョイン」するには1ヶ月程度はかかります。

単純に年間のブランクが少ない方が稼げます。

二つ目は、**受注した時点で売り上げはすでに発生しており、構築するための人員はコストである、とみなされることが多い**こと。

「コスト」であれば下げるほうが良いに決まっているので、単価も抑えられるし値上げも難しい傾向にあります。

なので「**継続的に稼働でき、システム開発を投資と捉えている」ことが多い継続案件を獲得していった方が良い**です。

私が今入っている案件も1年半程度継続しています。直前の案件は3年以上継続していました。

**「新規開拓は、既存顧客へのリセールの5倍のコストがかかる」というのはビジネスでよく知られている法則ですが、案件を継続させるとその間営業コストがかからなくなるので楽**です。

継続が見込める案件を選び、価値提供して契約を継続させる。これを意識して企業にアプローチしてみてください。

## 儲かっている会社の案件

ビジネスの大原則として「お金はあるところから取る（ないところからはどうやっても取れない）」というものがあります。

**身も蓋もない話ですが、「すでに儲かっている会社の案件」は単価が高い傾向**にあります。

**ビジネスが軌道に乗ってキャッシュが潤沢にある上、システム開発を「新しい価値を創出するための投資」として位置付ける会社が多い**からです。

「システム開発はコスト（なので人件費は安い方が良い）」という考え方をしている会社はどうしても単価が低く、値上げにも消極的です。

「今儲かっている会社」がどこか知るには、継続的な市場リサーチが欠かせません。

例えば生成AI、自動運転、SaaSなどジャンルごとに区切って自分なりに情報収集して仮説を作ることも必要ですし、非上場企業であっても官報の決算情報をまとめてくれるサイトや、スタートアップメディアの大型調達プレスリリースから懐具合を推測することはできます。

常に市場からの情報をアップデートしておく習慣をつけましょう。

## この章のまとめ

- 規模より商流
- 売り切りより継続案件
- 儲かっている企業は単価出やすい。常に業界動向をリサーチすべし
